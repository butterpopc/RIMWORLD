# 4단계: 킬존 v4 스트레스 테스트

- 도구: `tools/stress_sim.py`(몬테카를로, 조건마다 200회)
- 원문: `blueprint/stress_report.txt`, `blueprint/stress_v4.json`
- 아군: 돌격소총 6명. 사수 5자리 (153,176~180)와 2열 (152,178). 방어구 예리 0.45 [가정], 사격 8과 12 두 경우.

## 0. 모형과 한계

**코드에서 옮긴 규칙**(디컴파일 1.6, 요약)

| 규칙 | 코드 | 내용 |
|---|---|---|
| 명중 | `ShotReport` | 정확도^거리 × 무기 정확도 × 몸크기(0.5~2) × (1−엄폐). 거리·엄폐는 쏘는 쪽 실제 칸 기준 |
| 방어구 | `ArmorUtility` | 유효 방어 = max(방어−관통, 0). 난수가 그 절반 미만이면 0, 미만이면 피해 절반(예리→둔기) |
| 통증 기절 | `HediffSet.CalculatePain` | Σ(피해×0.0125) ÷ 체력배율 × 통증배율 ≥ 0.8이면 쓰러짐. 사람은 피해 64 |
| 보호막 벨트 | `CompShield` | 원거리·폭발 피해 × 0.033씩 에너지 감소. 깨지는 탄도 흡수. 근접은 그대로 통과 |
| 조준 | `Stance_Warmup` | 맞아도 조준이 끊기지 않는다. 표적이 쓰러지거나 사선이 끊길 때만 취소 |
| 로켓 표적 | `AttackTargetFinder.FriendlyFireBlastRadiusTargetScoreOffset` | 폭발 반경 안에 적이 많을수록 그 표적을 고른다 |
| 근접 위협 | `Verb_LaunchProjectile.Available` | AI 원거리 무기는 붙어 있는 근접 위협이 있으면 쏘지 않는다 |
| 폰 충돌 | `PawnUtility.PawnBlockedBy` | **같은 편끼리는 서로 통과한다** → 폭 1 미로가 습격대를 한 줄로 세우지 않는다. 적대 폰끼리만 막는다 |
| 아군 오사 | `VerbUtility.InterceptChanceFactorFromDistance` | 쏜 자리에서 5칸 안에 있는 아군은 내 탄에 맞지 않는다 → 2열 사수 가능 |
| 시야도둑 | `CompSightstealer` | 우리 폰에게서 14×lerp(0.33, 1, 밝기) 칸 안 + 사선이면 드러난다(어두우면 4.6칸, 밝으면 14칸). 맞거나, 공격하거나, 불붙으면 드러난다 |
| 휘청이는 자 | `JobGiver_ShamblerFight` | 막힌 문·벽을 부수고 들어오는 경로를 쓴다(문 비용 75, 문 체력 무시) |
| 저보호막 | `CompProjectileInterceptor` + `Projectile_Explosive` | 적대 투사체만 막고 아군 탄은 통과. 막힌 폭발물은 보호막 경계에서 터진다 |

**위키 수치**
- 돌격소총, 미니건, 저격소총, 둠스데이(반경 7.8, 폭탄 50, 조준 4.5초, 사거리 36)
- 센티피드(예리 72%, 1.9칸/초, 체력 432%)와 무기(중충전 블래스터·인페르노 사거리 27)
- 거대늘보(4.8칸/초, 체력 360%, 몸크기 4)
- 시야도둑(4.83칸/초, 체력 75%)
- 휘청이는 자(속도 ×0.7, 통증 없음)
- 네안데르탈(통증 ×0.5, 받는 피해 ×0.75)
- 보호막 벨트(1.1 / 0.033), 저보호막(반경 4.9, 30초, 250HP)

**[가정]** (결과를 좌우할 수 있음)
- 아군·동급 적의 방어구 0.45
- 근접 DPS와 타격 피해 일부
- 센티피드의 몸크기, 임피드의 속도·무기
- '살종양'은 정체를 확인하지 못해 중형 근접 살덩이 짐승으로 넣음
- 급소 모형: 몸통 40 / 머리 25 / 목 25 / 다리 30, 부위별 맞을 확률

**넣지 않은 것**
- 빗나간 탄의 오발 피해, 출혈, 화재 확산, 근접 회피
- 후퇴 교리(방폭문·근접 방어선): 모든 결과는 **사대에서 끝까지 버틴 경우**다. 사대에 근접 접촉이 생기면 단순 DPS 교환으로 처리했다.

## 2. 원인

1. **둠스데이: 터널 깊은 칸의 2:1 교전 + 밀집 사대.**
   - 사로 밖에서 사수를 볼 수 있는 가장 깊은 터널 칸 (180~181,182)에서는 사수가 2명만 보인다. 로켓병은 거기 서서 조준(4.5초)한다. 되쏘는 사수도 그 2명뿐이다.
   - 로켓 AI는 반경 안에 적이 많은 표적을 고른다(무기 XML에 아군 오사 회피 반경이 설정된 경우. 둠스데이 XML 값은 확인하지 못함). 사대 6명은 어느 표적이든 반경 7.8 안에 모두 들어간다.
2. **동급 10명: 엄폐 차이보다 머릿수가 크다.**
   - 적 명중률은 우리 엄폐 56%로 깎이지만, 10:6이면 탄 수가 1.7배다. 같은 편끼리는 통과하므로 미로가 한 줄로 세워 주지 않는다.
   - 터널 칸이 다 차면 나머지는 사로에 선다(엄폐 0). 그래도 여러 명이 동시에 쏜다.
3. **대군 근접: 처리 속도 부족.**
   - 22칸 사로를 근접 적이 건너는 시간은 약 5초다. 그동안 사수 6명이 맞히는 탄은 10~15발이다.
   - 네안데르탈 1명을 쓰러뜨리려면 약 16발, 휘청이는 자는 통증이 없어 급소 파괴가 필요하다. 근접 적이 몇 명만 넘어도 사대가 무너진다.
   - 시야도둑은 어두우면 4.6칸, 밝아도 14칸 안에서야 보인다.

## 4. 결론과 권고

**킬존 v4가 감당하는 것**
- 단일 정예: 센티피드, 사격 20 저격수, 보호막 단분자검
- 소수 근접: 네안데르탈 3, 거대늘보 3
- 엄폐 0 사로와 사거리 30.9 안 교전이 의도대로 작동한다.

**감당 못 하는 것과 대응**

| 위협 | 대응 | 근거 |
|---|---|---|
| 둠스데이·삼연발 미사일 | 무기고에 **저보호막 2개 상비**. 로켓 조준선(4.5초)이 보이면 전개. 로켓병을 최우선 사살 | 재시험에서 사망 0 |
| 동급 다수 원거리 | 사수 수 늘리기(목표 인구 12 → 사수 8~9), **아군 미니건**, 수류탄 | 머릿수 열세는 엄폐로 메울 수 없다 |
| 대군 근접(혼합·휘청·시야도둑) | 사대에서 버티지 않는다. 근접 적이 사로 중간을 넘으면 **D1 뒤로 후퇴 → 전실 → 대기실 → 근접 방어 문(156,187)**에서 1명씩 상대(층 2) | 같은 편끼리는 통과하지만, 적대 폰은 우리 폰에 막힌다 → 문간 1칸에서 3:1이 된다 |
| 휘청이는 자 | 문을 부수고 온다(코드). 문 뒤에서 버티기만으로는 안 되므로 근접 방어선 + 화염 | 4~5일 뒤 대사 탈진으로 죽는다(위키) |
| 시야도둑 | **사로 조명**(벽등). 어두우면 4.6칸, 밝으면 14칸에서 드러난다. 디스럽터 플레어, 범위 무기 | 조명만으로는 격퇴율이 약 10%p 오를 뿐 |
