## 0. 요약

**개념:** 북쪽 대리석·사암 산을 깎은 **단일 출입구 요새**. 생존에 필요한 모든 것(식량 생산·저장, 전력 저장, 의료, 숙소, 작업)은 두꺼운 산 지붕 아래에 두고, 산 밖에는 잃어도 버틸 수 있는 잉여 생산(밭·태양광·풍력)만 둔다.

**기계 검증 7항목 전부 통과 (오류 0)**
| 검사 | 결과 |
|---|---|
| V1 겹침·벽 누락·문 연결 | 0건 |
| V2 킬박스를 막으면 외부→내부 경로 0 (단일 출입구) | 통과 |
| V3 모든 내부 공간이 외부와 연결 | 통과 |
| V4 용도 없이 남는 굴착 칸 | 0칸 (기존 굴착 중 쓰지 않는 61칸은 전부 되메움) |
| V5 야외 시설이 암반·산지붕 위에 놓이지 않음 | 통과 |

## 4. 조건 ② 방어와 복구

### 4.1 킬박스 겸 현관
- 적은 MOUTH(165,170~175)를 한 줄로 지나 KB **남동 모서리 (165,176)**로 들어온다.
- 방어선은 **서쪽 끝**: 모래주머니 x=154 (z 176~183), 정착민 x 151~153, 포탑 (152,177)·(152,182).
- 적은 엄폐물 없는 **10칸**을 서쪽으로 건너야 하고, 방어선 뒤에는 에어록(문 2)이 있다.
- 냉동고 냉각기 3기(150,177/180/183)는 **방어선 뒤쪽 벽**에 있어 열을 KB로 내보낸다. KB는 입구로 바깥과 통해 있으므로 외기와 같은 온도로 취급될 것으로 본다 **[확인 필요]**.
- KB에는 가구·저장구역을 두지 않는다(적 엄폐물). 바닥은 다듬은 돌(불연), 조명 설치.
- 입구에 **문을 달지 않는다.** 열린 길이 있어야 일반 습격이 벽을 파지 않는다.

3. 모든 방·통로 조명.
4. 주 통로 방화문 3곳으로 구획 봉쇄.
